## Goal

A small package of pure functions computes the disproportionality statistics from a 2x2 table: PRR, chi-square, reporting odds ratio with its 95% interval, and the information component with its lower bound. Every signal in the project comes from these functions, so they are written once, without Spark, and tested hard.

## Context

For one drug and one reaction, with N total cases, n_d cases with the drug, n_r with the reaction and n_dr with both:

| | Reaction | No reaction |
|---|---|---|
| Drug | a = n_dr | b = n_d - a |
| Other drugs | c = n_r - a | d = N - n_d - n_r + a |

- This package must not import Spark. It runs inside executors, so everything must be serializable (case classes and objects are).
- The API in `docs/contracts.md` ("Statistics") is fixed. Do not rename or change return types. Additions are allowed.
- Read: `docs/contracts.md` (Statistics), `docs/pipeline-spec.md` section 4.

## Inputs

None. Function arguments only.

## Outputs

No tables. The public API:

```scala
package medsignal.stats

final case class TwoByTwo(a: Long, b: Long, c: Long, d: Long) {
  def n: Long = a + b + c + d
}
object TwoByTwo {
  /** None when any cell would be negative. Addition to the contract, used by G3 and V4. */
  def fromMarginals(total: Long, drug: Long, reaction: Long, both: Long): Option[TwoByTwo]
}

object Disproportionality {
  def prr(t: TwoByTwo): Option[Double]
  def chiSquare(t: TwoByTwo): Option[Double]
  def ror(t: TwoByTwo): Option[Double]
  def rorInterval(t: TwoByTwo): Option[(Double, Double)]
  def informationComponent(t: TwoByTwo): Double
  def ic025(t: TwoByTwo): Double
  def isCandidate(t: TwoByTwo): Boolean
  def expected(t: TwoByTwo): Double        // addition: (a+b)(a+c)/N, 0.0 when N is 0
}
```

## Implementation steps

1. Convert cells to `Double` before multiplying. Products of marginals overflow `Long` at FAERS scale (N is about 2 x 10^7).

2. `prr`: `(a / (a + b)) / (c / (c + d))`. `None` when `a + b == 0`, `c + d == 0` or `c == 0`. When `a == 0` and the rest is defined the result is `Some(0.0)`.

3. `chiSquare`, Yates-corrected:

   ```
   chi2 = N * (max(0, |a*d - b*c| - N/2))^2 / ((a+b) * (c+d) * (a+c) * (b+d))
   ```

   `None` when any of the four marginals is zero.

4. `ror`: `(a * d) / (b * c)`. `None` when `b == 0` or `c == 0`.

5. `rorInterval`: `exp(ln(ROR) ± 1.96 * sqrt(1/a + 1/b + 1/c + 1/d))`, returned as `(lower, upper)`. `None` when any cell is zero.

6. `informationComponent`: `log2((a + 0.5) / (E + 0.5))` with `E = expected(t)`. Always defined.

7. `ic025`, the approximate lower end of the 95% interval:

   ```
   IC025 = IC - 3.3 * (a + 0.5)^(-1/2) - 2 * (a + 0.5)^(-3/2)
   ```

   This is the approximation commonly attributed to Norén and colleagues (2013, shrinkage observed-to-expected ratios). It was written here from memory. Before anyone relies on it (G4 does), check the constants against the paper or against an independent published implementation of the information component, and record what you checked in `docs/results/G2.md`. If the reference disagrees, follow the reference and update this brief's test values.

8. `isCandidate`: `a >= 3` and `prr` is defined and `>= 2.0` and `chiSquare` is defined and `>= 4.0`. Undefined statistics give `false`.

9. `fromMarginals`: compute `a, b, c, d` as in the table above; `None` if any is negative.

10. Style: no `var`, no `null`, no exceptions for bad input; `Option` only. Scaladoc on each function with its formula.

## Tests

`DisproportionalitySpec` (`AnyFlatSpec with Matchers`, tolerance `+- 1e-3` unless stated):

- "worked example: 300 of 10,000 against 1% elsewhere". `TwoByTwo(300, 9700, 1000, 99000)`: `prr = 3.0` (tolerance 1e-9); `ror = 3.0619`; `rorInterval = (2.6867, 3.4894)`; `chiSquare = 309.66` (tolerance 0.01); `expected = 118.18`; `informationComponent = 1.3403`; `ic025 = 1.1495`; `isCandidate = true`.
- "small counts". `TwoByTwo(3, 7, 10, 980)`: `prr = 29.7`; `chiSquare = 44.218`; `ror = 42.0`; `informationComponent = 2.4739`; `ic025 = 0.4046`; `isCandidate = true`.
- "two cases are never a candidate". `TwoByTwo(2, 8, 10, 980)` gives `isCandidate = false`.
- "zero cells". `c = 0`: `prr`, `ror`, `rorInterval` are `None`, `isCandidate` is `false`, `informationComponent` is finite. `b = 0`: `ror` is `None`, `prr` is defined. `a = 0`: `prr = Some(0.0)`, `rorInterval = None`. All zeros: every `Option` is `None`, `informationComponent = 0.0`, nothing throws.
- "equal rates give no signal". `TwoByTwo(10, 90, 100, 900)`: `prr = 1.0`, `ror = 1.0`, `chiSquare = 0.0`, `isCandidate = false`.
- "large counts do not overflow". `TwoByTwo(50000, 2000000, 3000000, 15000000)`: every result is finite and positive.

`TwoByTwoSpec`:

- "from marginals": `fromMarginals(110000, 10000, 1300, 300)` gives `TwoByTwo(300, 9700, 1000, 99000)`.
- "impossible marginals": `fromMarginals(100, 10, 5, 8)` gives `None`.

`DisproportionalityPropertySpec`, over generated tables with all cells from 1 to 100,000:

- "PRR is 1 when rates are equal": for `TwoByTwo(k*x, k*y, x, y)` the PRR is 1 within 1e-9.
- "the interval contains the point estimate": `lower <= ror <= upper`.
- "chi-square is never negative".
- "ic025 is below the information component".
- "PRR rises with a": increasing `a` with `b, c, d` fixed never lowers PRR.
