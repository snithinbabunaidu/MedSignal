## Goal

A table, `gold.ClassSignal`, listing reactions that are unlabeled candidate signals for at least two drugs of the same drug class, with 2x2 counts pooled over the whole class. Some FDA warnings apply to a class (SGLT2 inhibitors and Fournier's gangrene); a single drug may have too few reports to stand out while the class does. The task also measures how many known class-wide warnings were flagged before the FDA (acceptance criterion 11).

## Context

- Read `docs/pipeline-spec.md` sections 4 and 10 ("Class effects"); `docs/acceptance-criteria.md` row 11; `docs/contracts.md` rows `formulary`, `case_drug`, `case_reaction`, `case`, `Signal`, `fda_warning`, section "Statistics"; `docs/tasks/V1.md` (`SignalHistory`, `Quarters`); `docs/tasks/V2.md` (`WarningMatcher`).
- Class membership comes from `bronze.formulary.drugClass`. A drug has one class there.
- Pooled counts are not the sum of the member drugs' counts: a case that lists two drugs of the class would be counted twice. Count distinct cases that have any drug of the class.
- The backlog lists only G3 as a dependency. The current-state table needs `labeledStatus`, so L5 must be merged. Criterion 11 says "before the FDA", which needs `gold.SignalHistory` (V1) and `bronze.fda_warning` (I8). The history part of this task runs only when those tables exist; if they do not, the stage says so and still writes the current-state table.
- Metrics are recorded by the runner (contracts.md decision 6): the stage returns `StageResult` and never calls `RunMetrics.record`.
- In `bronze.fda_warning` (loaded by I8), `target` is a formulary `drugClass` when `scope` is `class` and an `rxcui` when `scope` is `drug`; `terms` is a `Seq[String]` (separated by `;` in the CSV). Read the bronze tables, never the CSV files.

## Outputs

`gold.ClassSignal`, key (`drugClass`, `term`). The case class lives in this task's package, `medsignal.advanced.classeffect.ClassSignal`:

```scala
final case class ClassSignal(
  drugClass: String, term: String,
  drugsInClass: Int,                     // formulary drugs in the class
  drugsFlagged: Int,                     // of those, unlabeled candidates for this term today
  rxcuis: Seq[String],                   // the flagged drugs, sorted
  a: Long, b: Long, c: Long, d: Long,    // pooled: class and term, class not term, term not class, neither
  prr: Double, chiSquare: Double, ror: Double, rorLower: Double, rorUpper: Double,
  firstFlaggedQuarter: Option[String])   // first quarter the class rule held as of that quarter; None without SignalHistory
```

A row exists when `drugsFlagged >= minDrugs` and the pooled table passes `Disproportionality.isCandidate`.

## Implementation steps

1. Flagged members, pure rule: a signal row counts when `Disproportionality.isCandidate(TwoByTwo(a, b, c, d))` and `labeledStatus == "unlabeled"`. Write it once and use it for both `Signal` and `SignalHistory` rows.

2. `ClassCounts.byQuarter(cases, caseDrug, caseReaction, formulary, reactionTotals, quarterTotals): Dataset[ClassQuarterCount]` with `ClassQuarterCount(drugClass: String, term: String, quarter: String, classTermCases: Long, classCases: Long, termCases: Long, allCases: Long)`, all cumulative up to and including the quarter:
   - map `case_drug` to class with a broadcast join on the formulary and take distinct (`caseid`, `drugClass`);
   - per quarter (the case's `quarter` from `silver.case`, the quarter of first receipt): new distinct cases for class, and for class and term, from silver. The per-quarter term cases and total cases are the background totals: take them from gold `ReactionQuarterTotal` and `QuarterTotal`, do not recount them from silver. Each case sits in exactly one quarter, so per-quarter counts add up;
   - cumulative sums with a window ordered by quarter. Fill quarters that have no new cases, otherwise the running total has gaps: build the full grid of quarters for each key that ever appears, or carry the last value forward;
   - `a = classTermCases`, `b = classCases - a`, `c = termCases - a`, `d = allCases - classCases - termCases + a` (pipeline-spec section 4). No cross join of classes and terms: start from the class-term pairs that occur.

3. `ClassEffects.current(signals, formulary, counts): Dataset[ClassSignal]`: group flagged signals by (`drugClass`, `term`), keep groups with at least `minDrugs` distinct drugs, join the pooled counts of the latest quarter, compute statistics with `medsignal.stats.Disproportionality`, keep rows passing `isCandidate`. `prr`, `ror` and the interval return `Option`; a row that passes `isCandidate` has them defined, so a missing value there is a bug: fail loudly.

4. `ClassEffects.firstFlagged(history, formulary, counts): Dataset[(String, String, String)]` (class, term, quarter): the same rule applied per `asOfQuarter` using the history rows and the cumulative counts of that quarter; take the minimum quarter per (class, term). Left-join onto the current rows to fill `firstFlaggedQuarter`.

5. `ClassWarningCheck.check(firstFlagged, warnings, formulary): Seq[ClassWarningResult]` with `ClassWarningResult(warningId: String, drugClass: String, term: String, warningQuarter: String, firstFlaggedQuarter: Option[String], leadQuarters: Option[Int], flaggedBefore: Boolean)`: for warnings with `scope = "class"`, match `target` to `drugClass` (trim, upper case) and each term; a warning is flagged before the FDA when any of its terms has a class first-flagged quarter at least one quarter earlier than `Quarters.of(warningDate)`. Use the history-based first-flagged quarters, not the current table: a class signal that is labeled today is absent from `ClassSignal` but may well have been flagged in the past.

6. `ClassEffectStage` (`name = "advanced.classeffect"`, `cadences = Set(Quarterly, Full)`, `after = ["signals.signal", "labeltext.status", "bronze.formulary"]`, set in `stages/advanced.classeffect.conf` with `class = "medsignal.advanced.classeffect.ClassEffectStage"`): write `gold.ClassSignal` with `Delta.overwrite`. If `gold.SignalHistory` and `bronze.fda_warning` exist (`Delta.exists`), also run steps 4 and 5 and print the result table; otherwise log which table is missing. Return `StageResult(rowsIn = signal rows, rowsOut = class signal rows, rowsRejected = 0)`. Do not call `RunMetrics.record`; the runner records the stage.

## Tests

- `ClassCountsSpec` "a case with two drugs of the class counts once"; "cumulative counts include earlier quarters"; "a quarter with no new cases keeps the running total"; "d equals all cases minus class minus term plus both" (hand-computed table).
- `ClassEffectsSpec` "two unlabeled candidates in one class give a class signal"; "one flagged drug gives none"; "a labeled member does not count"; "members in different classes do not combine"; "a pooled table that fails the screen gives none"; "rxcuis are sorted and drugsInClass is 3"; "first flagged quarter is the first quarter two members were flagged".
- `ClassWarningCheckSpec` "class warning flagged two quarters early is counted"; "same-quarter flag is not before"; "drug-scope warnings are ignored"; "class signal labeled today is still found through history".
