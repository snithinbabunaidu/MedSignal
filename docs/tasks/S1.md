## Goal

`silver.case` exists with exactly one row per FAERS `caseid`: the highest `caseversion`, with FDA-deleted cases removed and the report date parsed to a date and a quarter. Every count in the project is a count of distinct cases, so every later table (S3, G1, G3) is only correct if this table is.

## Context

- FAERS re-sends a case as a new version each time it is followed up. Each version is one row in DEMO with the same `caseid`, a higher `caseversion` and a different `primaryid`. Only the latest version counts.
- The FDA also publishes lists of deleted cases. A deleted `caseid` must not appear in silver.
- Dates in FAERS are strings: `YYYYMMDD`, `YYYYMM` or `YYYY`.
- Read: `docs/contracts.md` (Common library, Conventions, Bronze tables, Silver tables), `docs/pipeline-spec.md` section 3, `docs/data-issues.md` rows 1, 2 and 7.
- This task builds the table in full from bronze. The incremental `MERGE` for a new quarter is task C2, which will call the functions written here, so keep them public and free of side effects.

## Implementation steps

1. Pure date functions (no Spark):

   ```scala
   final case class ParsedDate(date: java.sql.Date, isPartial: Boolean)
   object CaseDates {
     def parse(raw: Option[String]): Option[ParsedDate]
     def quarterOf(d: java.sql.Date): String          // 2024-08-15 -> "2024Q3"
   }
   ```

   Rules for `parse`, after trimming: 8 digits is a full date (`isPartial = false`); 6 digits is year and month, giving the first day of that month (`isPartial = true`); 4 digits is a year, giving 1 January (`isPartial = true`). This is "the earliest date consistent with the value". Anything else, an impossible date (month 13, 30 February) or a year before 1900 gives `None`. Use `java.time.LocalDate.of` inside `Try`.

2. Keep the latest version:

   ```scala
   object CaseDedup {
     def latestVersions(demo: Dataset[FaersDemo]): Dataset[FaersDemo]
     def dropDeleted(demo: Dataset[FaersDemo], deleted: Dataset[FaersDeleted]): Dataset[FaersDemo]
     def toCase(demo: Dataset[FaersDemo]): Dataset[Case]
     def build(demo: Dataset[FaersDemo], deleted: Dataset[FaersDeleted]): Dataset[Case]
   }
   ```

   ```scala
   val w = Window.partitionBy("caseid")
     .orderBy(col("caseversion").desc, col("quarter").desc, col("primaryid").desc)
   demo.withColumn("rn", row_number().over(w)).where(col("rn") === 1).drop("rn").as[FaersDemo]
   ```

   The two extra sort keys make the result deterministic when a version is repeated in two quarterly files.

3. Deleted cases: `demo.join(deleted.select("caseid").distinct(), Seq("caseid"), "left_anti")`. Rule (contracts.md, decision 12): a `caseid` on any deleted list is removed, whatever quarter the list came from. Uncertain: whether the FDA ever re-submits a deleted `caseid` later. Measure it (count deleted `caseid`s whose latest DEMO quarter is after the quarter of the list) and report the number in the results file; do not change the rule without the lead.

4. Map to `Case`:
   - `receivedDate` and `dateIsPartial` from `CaseDates.parse(fda_dt)`; `dateIsPartial = false` when the date is `None`.
   - `quarter` (contracts.md, decision 11): the quarter of `init_fda_dt` (first received) when `CaseDates.parse(init_fda_dt)` gives a date; otherwise the quarter of `fda_dt` when that parses; otherwise the bronze file `quarter`. A case that is followed up later therefore stays in its first quarter. `receivedDate` is still taken from `fda_dt`.
   - `ageYears` from `age` and `age_cod`: `YR` as is, `DEC` times 10, `MON` / 12, `WK` / 52.18, `DY` / 365.25, `HR` / 8766. Unknown or missing code, or a result outside 0 to 120, gives `None`.
   - `sex`: `M` or `F` (upper-cased), otherwise `None`. `country = occr_country`, `reporterType = occp_cod`, both trimmed, empty to `None`.

5. `CaseStage extends Stage`: `name = "silver.case"`, `cadences = Set(Quarterly, Full)`. In `run`: read both inputs, call `CaseDedup.build`, write with `Delta.overwrite`, and return `StageResult(rowsIn, rowsOut, 0)` where `rowsIn` is the DEMO row count and `rowsOut` the case count. Do not call `RunMetrics.record`: the runner (`StageRunner`) times the stage and records the metrics from the `StageResult`.

6. Rejects: bronze rows are already typed, so this stage writes no `Reject` rows. Superseded versions and deleted cases are not rejects; log both counts at INFO and put them in the results file so nothing disappears without a number.

7. `stages/silver.case.conf`: `class = "medsignal.silver.cases.CaseStage"` and `after = ["bronze.faers"]` (I2's stage, as listed in contracts.md).

## Tests

- `CaseDatesSpec`: "parses a full date" (`20240815` gives 2024-08-15, not partial); "parses year and month" (`202408` gives 2024-08-01, partial); "parses year only" (`2024` gives 2024-01-01, partial); "rejects bad values" (`20241340`, `abc`, empty, `None` give `None`); "computes quarters" (31 March is Q1, 1 April is Q2, 31 December is Q4).
- `CaseDedupSpec`: "two versions of a case leave one" (caseid 100 versions 1 and 2 give one row with `caseversion` 2 and its `primaryid`); "a deleted case disappears"; "a case with one version is kept unchanged"; "the same version in two quarters gives one row from the later quarter"; "age is converted to years" (24 `MON` gives 2.0; 5 `DEC` gives 50.0; 300 `YR` gives `None`); "quarter is the quarter of init_fda_dt" (`init_fda_dt = 20230210`, `fda_dt = 20240815`, file quarter `2024Q3` gives `2023Q1`); "quarter falls back to fda_dt when init_fda_dt is missing or unparseable"; "quarter falls back to the file quarter when both dates are missing".
- `CaseStageSpec` (mixes in `SparkTestSession`): writes fixture bronze tables, runs the stage with `StageRunner.run`, asserts `caseid` is unique in `silver.case` and the returned `StageResult` has the expected `rowsIn` and `rowsOut` (the runner, not the stage, writes the `run_metrics` row).
