## Goal

Every FAERS quarter on disk is parsed into typed bronze Delta tables partitioned by quarter, and every line that cannot be parsed is in `rejects` with its file, line number and reason. For every file, lines in equals rows loaded plus rows rejected. This is acceptance criterion 1 and the base of every later number.

Data facts: `$`-delimited, header row, no reliable quoting (switch quote handling off). Columns are found by header name because headers change between years. Expected headers in our range; confirm against the real 2014Q3 and latest files and record every variant:

- DEMO: `primaryid, caseid, caseversion, i_f_code, event_dt, mfr_dt, init_fda_dt, fda_dt, rept_cod, auth_num, mfr_num, mfr_sndr, lit_ref, age, age_cod, age_grp, sex, e_sub, wt, wt_cod, rept_dt, to_mfr, occp_cod, reporter_country, occr_country`
- DRUG: `primaryid, caseid, drug_seq, role_cod, drugname, prod_ai, ...`
- REAC: `primaryid, caseid, pt, drug_rec_act`
- OUTC: `primaryid, caseid, outc_cod` (an `outc_code` spelling may occur)
- INDI: `primaryid, caseid, indi_drug_seq, indi_pt`

Bronze is "as received": no upper-casing, no date parsing, no deduplication. Dates stay `Option[String]`.

This task also loads the sixth table, `bronze.faers_deleted` (the deleted-case lists), along with the five FAERS tables (contracts.md, decision 4, and the backlog); S1 needs it. `RunManifest` source `faers` is written only by this task, when a quarter is loaded (decision 5). The "row or error" wrapper is the serializable type defined by F4 (decision 8).

## Outputs

- `Tables.bronze("faers_demo" | "faers_drug" | "faers_reac" | "faers_outc" | "faers_indi" | "faers_deleted")`, case classes `FaersDemo`, `FaersDrug`, `FaersReac`, `FaersOutc`, `FaersIndi`, `FaersDeleted` with exactly the columns in contracts.md, partitioned by `quarter`. `quarter` is the folder name, not a file column.
- `Tables.ops("rejects")`, written with `Rejects.write(...)`: `Reject(source = "faers", file = "2024Q3/DRUG.txt", line = 1-based physical line number with the header as line 1, raw = the line, reason, runId)`.
- `run_manifest`: one entry per quarter, `source = "faers"`, `unit = quarter`, `checksum` = zip SHA-256, `watermark = Some(quarter)`.
- `run_metrics`: one row per run for the single stage `bronze.faers`, recorded by `StageRunner` from the returned `StageResult` (the stage never calls `RunMetrics.record`; contracts.md, decision 6). The per-table and per-file counts are kept by `FaersAccounting` and go to `docs/results/I2.md`.

## Implementation steps

1. Parsers. Lower-case and trim header names; look fields up by name. Rules:
   - Field count differs from the header's: `Left("expected N fields, found M")`. If F4 found a trailing `$` on lines, allow for it.
   - Required fields (non-`Option` in the case class) empty or not numeric where a number is needed: `Left("missing <col>")` or `Left("bad <col>: <value>")`.
   - `Option[String]` fields: empty gives `None`. `age: Option[Double]`: empty or non-numeric gives `None` (count non-numeric ages for the results file).
   - A required column missing from the header fails the whole file with a clear exception; it is a format change, not a bad row.
   - `DELETED.txt`: one `caseid` per line; if the first line is not numeric treat it as the header.
2. Loader (adapt to the F4 record):
   ```scala
   final case class Loaded[T](rows: Dataset[T], rejects: Dataset[Reject], linesIn: Long)
   def load[T <: Product: Encoder](path: String, file: String, quarter: String, ctx: RunContext)
                                  (mk: (String, String) => String => Either[String, T]): Loaded[T]
   ```
   Read lines with their index (`rdd.zipWithIndex`), take the header from index 0, build the parser inside `mapPartitions`, map each data line to a serializable "row or error" value, persist it, derive `rows` and `rejects` from it, unpersist after writing. Blank lines are rejects with reason `blank line`. `linesIn` counts data lines, not the header.
3. Stage `bronze.faers`, `cadences = Set(Cadence.Quarterly, Cadence.Full)`:
   - Quarters on disk = sub-folders of `Settings.rawDir("faers")` matching `\d{4}Q[1-4]`. Under `Quarterly`, process those not in `RunManifest.loaded("faers")`. Under `Full`, process all.
   - For each quarter in ascending order and each table: load; `Delta.overwrite(rows, Tables.bronze(t), Seq("quarter"))` (replaces only that quarter, so a re-run cannot duplicate rows); `Rejects.write(rejects)`; check `linesIn == rows + rejects`, and throw with the file name if not.
   - After all tables of a quarter succeed, `RunManifest.record("faers", quarter, checksum, Some(quarter))`.
   - A missing required file fails the quarter; a missing `DELETED.txt` is normal.
   - At the end return the totals over all six tables and all quarters processed as one `StageResult(rowsIn, rowsOut, rowsRejected)`. Do not call `RunMetrics.record`: `StageRunner` times the stage and records the metrics row. With nothing to do, return `StageResult(0, 0, 0)` and log `bronze.faers: no new quarters`.
4. `FaersAccounting.report(runId)`: one line per file, `quarter, table, lines, rows, rejects`, printed as a Markdown table for the results file.
5. Run: `sbt "pipeline/runMain medsignal.common.StageRunner bronze.faers --cadence full"`.
6. No `var`, no `null`; untyped operations stay inside the loader.

## Tests

- "parses a DEMO line from 2014Q3 and from 2024Q3 by header name".
- "DRUG with empty prod_ai gives None"; "DRUG with empty drugname is rejected with reason missing drugname".
- "short line is rejected with expected and found counts".
- "non-numeric primaryid is rejected"; "non-numeric age gives None".
- "double quote inside drugname is kept".

- "lines in equals rows plus rejects for every file".
- "tables are partitioned by quarter and carry the quarter".
- "running twice under Quarterly loads nothing the second time".
- "running twice under Full leaves the same row counts".
- "schema equals the case class schema" for all six tables.
- "deleted list loads into faers_deleted".
- "records one manifest entry per quarter".
- "returns the summed counts in StageResult and StageRunner.run records one bronze.faers metrics row".
