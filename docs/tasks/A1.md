## Goal

A pipeline stage that copies the formulary-scoped gold tables into the serving database over JDBC, replacing every published table in one transaction. The application reads only this database, so it stays up and readable while Spark rebuilds or publishes. Spark is not a serving engine; this job is the only bridge between the two.

## Outputs

Serving tables. Names are the gold field names in lower snake case, with four deliberate differences: `labeled_reaction` gains `rxcui` (the API looks up by drug and there is no `label` table in serving); `signal.sections_searched` is one string of LOINC codes joined by commas (arrays are not portable between H2 and PostgreSQL); `change_event` uses `before_value` and `after_value`; `extraction_score` uses `precision_score` and `recall_score` (avoid SQL keywords).

```sql
CREATE TABLE IF NOT EXISTS drug (
  rxcui VARCHAR PRIMARY KEY, name VARCHAR NOT NULL, drug_class VARCHAR, on_formulary BOOLEAN NOT NULL);

CREATE TABLE IF NOT EXISTS signal (
  rxcui VARCHAR NOT NULL, term VARCHAR NOT NULL,
  a BIGINT NOT NULL, b BIGINT NOT NULL, c BIGINT NOT NULL, d BIGINT NOT NULL,
  prr DOUBLE PRECISION, chi_square DOUBLE PRECISION, ror DOUBLE PRECISION,
  ror_lower DOUBLE PRECISION, ror_upper DOUBLE PRECISION,
  serious_share DOUBLE PRECISION, growth4q DOUBLE PRECISION, score DOUBLE PRECISION,
  first_flagged_quarter VARCHAR, indication_flag BOOLEAN NOT NULL, spike_flag BOOLEAN NOT NULL,
  labeled_status VARCHAR NOT NULL, deciding_set_id VARCHAR, deciding_version INT,
  passage VARCHAR, sections_searched VARCHAR NOT NULL, triage_status VARCHAR NOT NULL,
  PRIMARY KEY (rxcui, term));

CREATE TABLE IF NOT EXISTS adverse_event_stat (
  rxcui VARCHAR NOT NULL, term VARCHAR NOT NULL, quarter VARCHAR NOT NULL,
  cases BIGINT NOT NULL, serious_cases BIGINT NOT NULL, death_cases BIGINT NOT NULL,
  cumulative_cases BIGINT NOT NULL, PRIMARY KEY (rxcui, term, quarter));

CREATE TABLE IF NOT EXISTS labeled_reaction (
  rxcui VARCHAR NOT NULL, set_id VARCHAR NOT NULL, version INT NOT NULL, term VARCHAR NOT NULL,
  extractor_version VARCHAR NOT NULL, loinc VARCHAR NOT NULL, passage VARCHAR NOT NULL,
  start_offset INT NOT NULL, end_offset INT NOT NULL, negated BOOLEAN NOT NULL,
  PRIMARY KEY (set_id, version, term, extractor_version));

CREATE TABLE IF NOT EXISTS recall (
  recall_number VARCHAR PRIMARY KEY, rxcui VARCHAR, classification VARCHAR NOT NULL,
  status VARCHAR NOT NULL, reason VARCHAR, product_text VARCHAR, firm VARCHAR,
  initiation_date DATE, report_date DATE NOT NULL, termination_date DATE,
  source_url VARCHAR, on_formulary BOOLEAN NOT NULL);

CREATE TABLE IF NOT EXISTS change_event (
  run_date DATE NOT NULL, kind VARCHAR NOT NULL, object_key VARCHAR NOT NULL,
  rxcui VARCHAR, before_value VARCHAR, after_value VARCHAR,
  PRIMARY KEY (run_date, kind, object_key));

CREATE TABLE IF NOT EXISTS run_metrics (
  run_id VARCHAR, stage VARCHAR NOT NULL, rows_in BIGINT, rows_out BIGINT, rows_rejected BIGINT,
  duration_ms BIGINT, newest_source_date VARCHAR, recorded_at TIMESTAMP);

CREATE TABLE IF NOT EXISTS extraction_score (
  extractor_version VARCHAR NOT NULL, precision_score DOUBLE PRECISION,
  recall_score DOUBLE PRECISION, negation_accuracy DOUBLE PRECISION, scored_at TIMESTAMP);
```

## Implementation steps

1. Define the trait.

   ```scala
   trait Publisher {
     def table: String                      // serving table name, e.g. "signal"
     def ddl: Seq[String]                   // CREATE TABLE / INDEX IF NOT EXISTS, portable SQL
     def columns: Seq[String]               // serving columns, in order
     def frame(ctx: RunContext): DataFrame  // exactly these columns, already scoped
   }
   ```

2. `PublisherRegistry.load(): Seq[Publisher]` walks the classpath folder `medsignal/publish` recursively (so `medsignal/publish/trials/*.conf` is found later), reads `class` from each `.conf`, and instantiates it by reflection (a class with a no-argument constructor). Handle both a directory on disk (tests) and a jar (spark-submit). Look at how C1 loads `stages/` and use the same approach. Fail with a clear message if two publishers name the same table.

3. Each publisher reads its gold table with `Delta.read[T](Tables.gold("..."))`, applies the scope from the Inputs table, and renames to snake case with an explicit `select`. Where a publisher needs the formulary list itself, read `bronze.formulary` (`FormularyDrug`, loaded by F6), never the CSV, and join it with a broadcast. `SignalPublisher` converts `sectionsSearched` with `concat_ws(",", ...)`.

4. `PublishStage` (`name = "publish.serving"`, `cadences = Set(Daily, Weekly, Quarterly, Full)`), in `run`:
   1. Load publishers. Run every `ddl` statement (idempotent).
   2. For each publisher, write `frame(ctx)` to a staging table `stg_<table>` with Spark: `df.write.mode("overwrite").jdbc(url, s"stg_$table", props)`. Cache the frame or count the staging table to get the row count.
   3. Open one connection, `setAutoCommit(false)`, and for every publisher run `DELETE FROM <table>` then `INSERT INTO <table> (<columns>) SELECT <columns> FROM stg_<table>`. Commit once after the last table. On any exception roll back and rethrow, so the serving tables are unchanged and the run fails.
   4. After commit, check `SELECT COUNT(*)` of each table equals the staged count; throw if not. Drop the staging tables.

   Use `DELETE`, not `TRUNCATE` or drop-and-rename. Table definition statements are not transactional in H2, and `TRUNCATE` blocks readers in PostgreSQL; plain row changes are transactional in both, and a reader on the default isolation level keeps seeing the old rows until the commit. The reader test below proves it on H2; check it once by hand on PostgreSQL.

5. Spark quotes column names when it creates the staging table. With `DATABASE_TO_LOWER=TRUE` on H2 and lower-case column names in the frame this works on both databases; the round-trip test will catch a mismatch.

6. Metrics: do not call `RunMetrics.record`. Return `StageResult(rowsIn = total scoped gold rows, rowsOut = total serving rows, rowsRejected = 0)`; the runner records it under `publish.serving`. Log one line per table with its gold and serving counts, and put the per-table counts in `docs/results/A1.md`.

7. `stages/publish.serving.conf`: `class = "medsignal.publish.PublishStage"`, `after = ["signals.signal", "labeltext.status", "triage.status", "changes.events"]` (stage names from contracts.md, "Stage names"). A4's stage `triage.status` must run before publish so the published `signal` table carries the triage status: check whether C1 tolerates an `after` entry for a stage that does not exist yet. If it does, include `"triage.status"` now. If it does not, leave it out and note in the pull request that A4 needs a one-line follow-up.

## Tests

Fixtures in `pipeline/src/test/resources/A1/`: small JSON or CSV files for each gold table (3 drugs, one off the formulary; 4 signals; stats for 5 pairs of which 4 are signals; 2 recalls on the formulary, 1 off it, 1 unresolved). Tests use `SparkTestSession` and an in-memory H2 URL `jdbc:h2:mem:a1;MODE=PostgreSQL;DATABASE_TO_LOWER=TRUE;DB_CLOSE_DELAY=-1`.

- `PublishStageSpec` "copies every table with matching counts": after `run`, each serving count equals the scoped gold count.
- "is idempotent": run twice; counts unchanged, no staging tables left.
- "keeps old rows readable until commit": publish once; start a second publish with a test hook that runs just before commit; from a second connection the hook counts `signal` and gets the old count; after commit it gets the new count.
- "rolls back every table when one fails": a publisher whose staging frame violates the primary key; after the failure all tables still hold the first publish.
- "never touches triage_event": create the table with one row; it is still there after publish.
- `PublisherScopeSpec` "drops off-formulary drugs", "keeps unresolved recalls", "publishes stats only for signal pairs", "publishes only reference-label reactions with rxcui filled", "joins sectionsSearched with commas".
- `PublisherRegistrySpec` "finds a publisher in a sub-folder" (a test descriptor under `medsignal/publish/testsub/`), "rejects duplicate table names".
