## Goal

A command that puts every FAERS quarterly ASCII zip from 2014 Q3 to the latest quarter, unpacked, under `data/raw/faers/`, with a checksum and size recorded per file. Running it again downloads nothing. I2 reads these files.

## Context

Read `docs/data-sources.md` (FAERS row and tables), `docs/contracts.md` (Paths) and `docs/pipeline-spec.md` section 6 (FAERS row).

This task depends on F3 only, not on F7, so it uses no Spark and nothing from `medsignal.common`. Config comes straight from `com.typesafe.config.ConfigFactory.load()`: `medsignal.dataDir`, `medsignal.faers.listingUrl`, `medsignal.faers.firstQuarter`, `medsignal.http.*`. "The manifest" here is a plain file next to the downloads (below). The Delta `run_manifest` records what has been loaded into bronze and is written by I2; if this downloader wrote to it, I2 would think the quarters were already loaded.

What is known and what must be verified:

- The listing page is `https://fis.fda.gov/extensions/FPD-QDE-FAERS/FPD-QDE-FAERS.html`. Zip links are believed to look like `https://fis.fda.gov/content/Exports/faers_ascii_2024q3.zip`, with the letter case of `q` varying by year. Do not build URLs from a pattern: fetch the page and take every `href` matching `(?i)faers_ascii_(\d{4})q([1-4])\.zip`. If the page turns out to be rendered by script with no links in the HTML, fall back to the pattern, try both cases, and say so in the results file.
- Inside a zip: a folder named `ascii` or `ASCII` with `DEMOyyQn.txt`, `DRUG`, `REAC`, `OUTC`, `INDI`, `RPSR`, `THER` files, plus documents. Letter case varies.
- Deleted-case lists: believed to be inside the quarterly zips from about 2019 on, in a folder named like `Deleted` or `DELETED`, one case id per line. Open one old and one recent zip and confirm where they are and whether they have a header. If the FDA publishes them separately, download those too.

## Inputs

The listing page and the zip files.

## Outputs

```
data/raw/faers/zips/faers_ascii_2024q3.zip
data/raw/faers/2024Q3/DEMO.txt  DRUG.txt  REAC.txt  OUTC.txt  INDI.txt  DELETED.txt (when present)
data/raw/faers/manifest.tsv
```

File names are normalized on unpack: upper-case table name, `.txt`, in a folder named by the contract's quarter format (`2024Q3`). RPSR, THER and documents are not unpacked. File bytes are never changed.

`manifest.tsv` (tab-separated, header row, one row per zip, rewritten atomically via a temp file and rename):

`quarter`, `url`, `zipFile`, `bytes`, `sha256`, `downloadedAt` (ISO-8601 UTC), `files` (comma-separated unpacked names).

## Files to create

Under `pipeline/src/main/scala/medsignal/download/faers/`:

- `FaersQuarter.scala`: `final case class FaersQuarter(year: Int, q: Int)` with `label` (`2024Q3`), ordering, `parse`.
- `FaersListing.scala`: pure functions that turn listing HTML into `Seq[(FaersQuarter, String)]`.
- `FaersManifest.scala`: `ManifestRow`, `read`, `write`.
- `FaersUnzip.scala`: entry-name classification and extraction.
- `FaersDownloader.scala`: `main`.

Under `pipeline/src/test/scala/medsignal/download/faers/`: `FaersListingSpec.scala`, `FaersManifestSpec.scala`, `FaersUnzipSpec.scala`, `FaersDownloaderSpec.scala`.

Fixtures under `pipeline/src/test/resources/I1/`: `listing.html` (trimmed copy of the real page), `tiny_2024q3.zip` and `tiny_2015Q1.zip` (hand-made, a few lines per file, different folder and name case, one with a deleted list).

## Implementation steps

1. `FaersListing.links(html: String, first: FaersQuarter): Seq[(FaersQuarter, String)]`: regex over `href`s, resolve relative URLs against the page URL, drop quarters before `first`, de-duplicate by quarter, sort.
2. `FaersUnzip.classify(entryName: String): Option[String]`: returns the normalized target name. Rules, case-insensitive on the base name: `^(DEMO|DRUG|REAC|OUTC|INDI)\d{2}Q[1-4]\.txt$` gives `<TABLE>.txt`; a `.txt` entry whose path or name contains `delete` gives `DELETED.txt`; everything else `None`. Adjust the patterns to what the real zips contain and record the variants found.
3. HTTP: JDK `java.net.http.HttpClient`, follow redirects, timeout and retries (with a pause that doubles) from config, a `User-Agent` such as `medsignal-course-project`. Download to `<name>.zip.part`, then rename. Compute SHA-256 while streaming.
4. Download seam for tests: `trait Fetcher { def get(url: String): Either[String, java.io.InputStream] }`; the real one uses `HttpClient`, tests pass a fake.
5. `FaersDownloader.run(fetcher, dataDir, listingUrl, first): Either[String, Summary]` with `Summary(listed: Int, downloaded: Int, skipped: Int, failed: Seq[String])`:
   - read `manifest.tsv` (missing file means empty);
   - for each listed quarter: skip when a manifest row exists, the zip is on disk and its size equals the row's `bytes`; otherwise download, unpack, add the row and rewrite the manifest immediately (a crash keeps finished quarters);
   - a quarter whose zip lacks any of the five tables is a failure with a message, not a silent skip;
   - one failed quarter does not stop the others; exit code is non-zero when `failed` is non-empty.
6. `main`: `sbt "pipeline/runMain medsignal.download.faers.FaersDownloader"`; optional `--only 2024Q3`. Prints the summary and, on a second run, `Nothing to download`.
7. No `var`, no `null`; errors as `Either` or `Try`.

## Tests

- `FaersListingSpec` "finds every quarter link in the saved page"; "accepts upper and lower case q"; "drops quarters before 2014Q3"; "resolves a relative link".
- `FaersQuarter` "parses 2024q3 and 2024Q3 to label 2024Q3"; "orders 2014Q4 before 2015Q1".
- `FaersUnzipSpec` "classifies ascii/DEMO24Q3.txt and ASCII/demo15q1.txt as DEMO.txt"; "ignores RPSR, THER and pdf entries"; "classifies a deleted list"; "extracts the five tables from tiny_2024q3.zip with unchanged bytes".
- `FaersManifestSpec` "write then read returns the same rows".
- `FaersDownloaderSpec` (fake `Fetcher`, temp folder) "downloads two quarters and writes two manifest rows"; "second run downloads nothing"; "re-downloads when the zip is missing"; "reports a quarter whose zip lacks DRUG as failed and continues".
