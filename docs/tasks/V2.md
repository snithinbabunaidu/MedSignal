## Goal

For each known FDA warning in the answer key, find the first quarter in which MedSignal would have shown a matching drug and reaction as an unlabeled candidate signal, and compare it with the date of the FDA warning. The result is `gold.BacktestResult` plus two numbers: the share of warnings flagged before the FDA, and the median lead time in quarters (acceptance criterion 10).

## Context

- Read `docs/acceptance-criteria.md` row 10; `docs/pipeline-spec.md` section 10; `docs/data-sources.md` section "Known FDA warnings in the formulary's classes"; `docs/contracts.md` rows `fda_warning`, `formulary` and section "Statistics"; `docs/tasks/V1.md` for `SignalHistory` and `Quarters`.
- `FdaWarning(warningId, scope, target, terms: Seq[String], warningDate: Date, sourceUrl)`. `scope` is `drug` or `class`. `target` is an `rxcui` when `scope` is `drug` and a formulary `drugClass` when `scope` is `class` (contracts.md decision 17). In `fda_warnings.csv` the terms are separated by `;`; in `bronze.fda_warning` (loaded by I8, stage `bronze.fda_warning`) `terms` is already a `Seq[String]`. Read the bronze table, never the CSV. `FdaWarning` and `FormularyDrug` are imported from the packages of I8 and F6, not redefined.
- A warning matches a set of (rxcui, term) pairs: every target drug crossed with every term. It counts as flagged in quarter Q when at least one of those pairs is, as of Q, a candidate (`Disproportionality.isCandidate` on its counts) with `labeledStatus = "unlabeled"`.
- Honest limits to state in the results: FAERS data here starts in 2014Q3, so a 2015 warning can have a lead of at most a few quarters; a quarter's FAERS file is published some time after the quarter ends, so "flagged in Q" really means "could have been seen shortly after Q" (check the usual publication delay on the FDA page in data-sources.md and report it); about 20 warnings is a small sample.
- The backlog exit condition says "Backtest table and page". This task owns no path in the app or the publish job, so the "page" here is the results file `docs/results/V2.md`. An app page needs a backlog change.

## Outputs

`gold.BacktestResult`, key `warningId`. The case classes live in this task's package, `medsignal.backtest.scoring`:

```scala
final case class BacktestResult(
  warningId: String,
  scope: String,                         // drug or class
  target: String,
  terms: Seq[String],
  warningDate: java.sql.Date,
  warningQuarter: String,                // quarter containing warningDate
  matchedDrugs: Int,                     // formulary drugs the target resolved to
  pairsWithReports: Int,                 // matched (rxcui, term) pairs that ever appear in SignalHistory
  firstFlaggedQuarter: Option[String],   // first quarter any matched pair was an unlabeled candidate
  flaggedRxcui: Option[String],          // the pair that flagged first (highest score on ties)
  flaggedTerm: Option[String],
  leadQuarters: Option[Int],             // index(warningQuarter) - index(firstFlaggedQuarter)
  flaggedBefore: Boolean,                // leadQuarters >= 1
  firstNoLabelQuarter: Option[String],   // first quarter a matched pair was a candidate with no_label
  sourceUrl: String)
```

Summary (returned by a function, printed, and written to the results file):

```scala
final case class BacktestSummary(
  warnings: Int, matchable: Int, everFlagged: Int, flaggedBefore: Int,
  shareFlaggedBefore: Double,            // flaggedBefore / warnings
  medianLeadFlaggedBefore: Option[Double],  // median leadQuarters over flaggedBefore rows
  medianLeadEverFlagged: Option[Double])    // median over every flagged row; may be negative
```

## Implementation steps

1. `WarningMatcher.pairs(warnings: Dataset[FdaWarning], formulary: Dataset[FormularyDrug]): Dataset[WarningPair]` with `WarningPair(warningId, rxcui, term)`:
   - normalise text with trim and upper case on both sides;
   - `scope = "drug"`: `target` equals the formulary `rxcui`;
   - `scope = "class"`: `target` equals the formulary `drugClass`;
   - explode `terms`, upper-cased and trimmed (the FAERS term convention);
   - a warning that resolves to no drug gets `matchedDrugs = 0` and stays in the result as not flagged. Do not drop it: a silent drop would inflate the share.

2. `BacktestScoring.score(history: Dataset[SignalHistory], pairs: Dataset[WarningPair], warnings: Dataset[FdaWarning]): Dataset[BacktestResult]`:
   - join `history` to `pairs` on (`rxcui`, `term`) (pairs are few: broadcast them);
   - candidate test as a typed filter: `Disproportionality.isCandidate(TwoByTwo(h.a, h.b, h.c, h.d))`;
   - flagged rows: candidate and `labeledStatus == "unlabeled"`. Per warning take the minimum `asOfQuarter`; among rows of that quarter take the highest `score` for `flaggedRxcui` and `flaggedTerm`;
   - `firstNoLabelQuarter`: the same with `labeledStatus == "no_label"`. It is reported, not counted as a flag: with no label there was nothing to compare against;
   - `warningQuarter = Quarters.of(warningDate)`; `leadQuarters = Quarters.index(warningQuarter) - Quarters.index(firstFlaggedQuarter)`; `flaggedBefore = leadQuarters.exists(_ >= 1)`. A flag in the same quarter as the warning does not count as before.

3. `BacktestScoring.summary(results: Seq[BacktestResult]): BacktestSummary`. `matchable` = rows with `pairsWithReports > 0`. The denominator of `shareFlaggedBefore` is all warnings, including those that could not be matched. Median: sort; for an even count take the mean of the two middle values; `None` for an empty set.

4. `BacktestStage` (`name = "backtest.scoring"`, `cadences = Set(Full)`): skip with a log line unless `medsignal.evaluation.enabled` is `true`; `Delta.overwrite` the result to `Tables.gold("BacktestResult")`; print the summary and a table of all rows; return `StageResult(rowsIn = warnings, rowsOut = result rows, rowsRejected = 0)`. Do not call `RunMetrics.record`; the runner records the stage. The stage file `stages/backtest.scoring.conf` holds `class = "medsignal.backtest.scoring.BacktestStage"` and `after = ["backtest.asof", "bronze.fda_warning", "bronze.formulary"]`.

5. Report in `docs/results/V2.md`:
   - the headline for criterion 10: `shareFlaggedBefore` (target 60%) and `medianLeadFlaggedBefore` (target 2 quarters), and beside it `medianLeadEverFlagged`, because a median over successes only is flattering;
   - a table with one line per warning: target, terms, warning date, first flagged quarter, lead, and for unflagged warnings the reason (no matching drug, term never reported, already labeled when first a candidate, never passed the screen);
   - the sensitivity figure: the share if a one-quarter publication delay is charged (`leadQuarters >= 2`);
   - the limits listed in Context.

6. Terms in the answer key that match no FAERS term at all (`pairsWithReports = 0`) are usually wording problems. List them for I8's owners; do not edit `fda_warnings.csv` from this branch.

## Tests

Fixtures in `pipeline/src/test/resources/V2/`: `fda_warning.json` (W1 class SGLT2 with term KETOACIDOSIS dated 2015-05-15; W2 drug by rxcui with two terms dated 2017-05-16; W3 drug by rxcui whose pair is never unlabeled; W4 drug with an rxcui that is not on the formulary), `formulary.json` (3 SGLT2 drugs, 2 others), `signal_history.json` (hand-made rows by quarter).

- `WarningMatcherSpec` "class scope expands to every drug of the class" (3 drugs times 1 term); "class scope matches drugClass ignoring case and surrounding spaces"; "drug scope matches by rxcui"; "a drug-scope target is never matched against a class name"; "several terms give one pair each"; "unknown target gives no pairs".
- `BacktestScoringSpec` "first flagged quarter is the earliest unlabeled candidate" (W1 flagged 2014Q4, warning 2015Q2, lead 2, flaggedBefore true); "a labeled row does not flag"; "a row failing the screen does not flag" (a = 2); "same-quarter flag is not before" (lead 0); "flag after the warning has negative lead"; "never-flagged warning has no quarter and flaggedBefore false"; "unmatched warning is kept with matchedDrugs 0"; "no_label is recorded separately".
- `BacktestSummarySpec` "share uses all warnings as denominator" (2 of 4 is 0.5); "median of leads 1, 2, 5 is 2"; "median of 2 and 4 is 3"; "median of none is None".
