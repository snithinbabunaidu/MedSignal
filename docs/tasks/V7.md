## Goal

For a drug and reaction on the drill-down, show whether the same reaction was reported in clinical trial results for that drug: how many trials, how many participants affected out of how many at risk, and a link to one trial. It is a second opinion beside the FAERS counts, not a proof.

## Outputs

`gold.TrialEvidence`, key (`rxcui`, `term`), `Delta.overwrite`:

```scala
package medsignal.publish.trials
final case class TrialEvidence(
  rxcui: String,
  term: String,          // normalized as FAERS terms are
  trials: Long,          // distinct nctId
  affected: Long,        // sum over arms of the drug
  atRisk: Long,
  seriousTrials: Long,   // distinct nctId with a serious row
  exampleNctId: String)  // the trial with the most affected; ties: smallest nctId
```

Serving table `trial_evidence(rxcui, term, trials, affected, at_risk, serious_trials, example_nct_id)`, primary key (`rxcui`, `term`).

`GET /api/drugs/{rxcui}/trials?term=` returns `List[TrialEvidenceRow]`: the fields above plus `trialUrl = "https://clinicaltrials.gov/study/" + exampleNctId`. Open one such URL in a browser to verify the form before relying on it. Unknown drug or no rows: 200 with an empty list.

## Implementation steps

1. `TrialEvidenceBuilder.build(events: Dataset[TrialAdverseEvent]): Dataset[TrialEvidence]`: keep rows with `rxcui` defined and `atRisk > 0`; normalize `term`; a serious and an other row for the same (trial, arm, term) are both kept in bronze, so first reduce to one row per (`nctId`, `intervention`, `rxcui`, `term`) taking the maximum `affected` and `atRisk` and `serious = any`; then aggregate per (`rxcui`, `term`). Rows without `rxcui` are counted, not rejected (decision 18).
2. `matchRate(evidence, signals)`: share of `gold.Signal` pairs with a `TrialEvidence` row, and share of evidence terms that equal any FAERS term.
3. `TrialEvidenceStage` (`name = "advanced.trial_evidence"`, `cadences = Set(Full)`): build, overwrite, return `StageResult(rowsIn, rowsOut, 0)`. The runner records metrics (decision 6).
4. `TrialEvidencePublisher extends Publisher`: `table = "trial_evidence"`, DDL above, frame scoped to formulary drugs with a broadcast join. If the gold table is missing, publish an empty frame (`Delta.readOrEmpty`).
5. `TrialsRoutes extends RouteGroup`: doobie query by `rxcui`, optional `term` upper-cased and trimmed, ordered by `affected` descending. If the table does not exist, return 404 so A3 hides the panel.
6. `docs/results/V7.md`: rows in bronze, rows without `rxcui`, evidence rows, both match rates, ten unmatched trial terms by frequency, and the verified URL form.
