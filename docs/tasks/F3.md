## Goal

A guide that takes a new machine to a passing `sbt test`, and one configuration file that holds the paths and connection settings the pipeline uses. Code never hard-codes a path (contracts.md, Paths), so this file is where they live. Thresholds and other tunables do not live here: each task keeps its own defaults in `pipeline/src/main/resources/conf.d/<task id>.conf` (contracts.md, decision 9).

## Context

Read `docs/contracts.md` (Paths, Serving database, decision 9), `docs/architecture.md` (Layers, Cadence) and `docs/results/F1.md` (resolved versions, any `publishLocal` steps).

Spark on native Windows needs `winutils.exe` and `hadoop.dll` and still breaks on file permissions. The supported setups are WSL2 (Ubuntu) or Docker. Nithin works on Windows 11, so the WSL2 path must be complete.

Division of work with F7: this task writes the `application.conf` file. The Scala object that reads it (`medsignal.common.Settings`) belongs to F7. Downloader I1 reads the file directly with `com.typesafe.config.ConfigFactory`. Agree the key names below with Nithin before merging; later tasks put their own tunables, with defaults, in their own `pipeline/src/main/resources/conf.d/<task id>.conf` (loaded by `Settings.config` alongside this file), so they never need to edit this file.

## Implementation steps

1. `docs/setup.md`, in this order, with commands that can be pasted:
   1. Prerequisites: Git, JDK 21 (Temurin), sbt 1.x. For WSL2: `wsl --install -d Ubuntu`, then install the JDK and sbt inside Ubuntu (SDKMAN is the simplest). State clearly: clone the repository inside the Linux file system (`~/MedSignal`), not under `/mnt/c`, because Delta writes are slow and permission checks fail there.
   2. Docker alternative: a `docker run` command with a JDK 21 and sbt image, the repository mounted, and `~/.ivy2` and `~/.cache/coursier` mounted as volumes. Check the image tag exists before writing it down.
   3. Professor's libraries: only if `docs/results/F1.md` says they must be published locally, repeat the commands.
   4. First build: `sbt test`; expected time and what a pass looks like.
   5. Data directory layout: copy the table from contracts.md (Paths) and say which folders are git-ignored. Note: `.gitignore` currently ignores `data/raw`, `bronze`, `silver`, `gold`, `serving` but not `data/ops` or `data/interchange`; tell the reader not to commit those (the lead will fix `.gitignore` in a separate `[Chore]`).
   6. Configuration: how to override a key (`-Dmedsignal.dataDir=/path` or an environment variable), and that secrets (serving password, openFDA key) are never committed.
   7. Running things: `sbt "pipeline/runMain <class> <args>"`, memory setting, where Spark's UI is (port 4040).
   8. IDE: IntelliJ or Metals with two Scala versions; point the IDE at the WSL JDK.
   9. Troubleshooting: `winutils` error (you are on native Windows; move to WSL2), `InaccessibleObjectException` (missing `--add-opens`; run through sbt), out of memory, port 4040 busy.
   10. Formatting and the commit format: link to `CONTRIBUTING.md`.
2. `application.conf` (HOCON). Every value can be overridden by a system property of the same name.
   ```hocon
   medsignal {
     dataDir = "data"
     dataDir = ${?MEDSIGNAL_DATA_DIR}
     spark { master = "local[*]", shufflePartitions = 16 }
     serving {
       url = "jdbc:h2:file:./data/serving/medsignal"
       user = "sa"
       password = ""
       password = ${?MEDSIGNAL_SERVING_PASSWORD}
     }
     faers {
       firstQuarter = "2014Q3"
       listingUrl = "https://fis.fda.gov/extensions/FPD-QDE-FAERS/FPD-QDE-FAERS.html"
     }
     rxnorm { prescribeUrl = "https://download.nlm.nih.gov/rxnorm/RxNorm_full_prescribe_current.zip"
              rxclassBaseUrl = "https://rxnav.nlm.nih.gov/REST/rxclass" }
     openfda { downloadIndexUrl = "https://api.fda.gov/download.json"
               enforcementUrl = "https://api.fda.gov/drug/enforcement.json"
               apiKey = ${?OPENFDA_API_KEY} }
     trials { baseUrl = "https://clinicaltrials.gov/api/v2/studies" }
     http { requestsPerSecond = 4, retries = 3, timeoutSeconds = 120 }
   }
   ```
   Open each URL once and correct any that has moved; these are believed right but not verified. This file holds paths and connection settings only (contracts.md, decision 9). Do not add thresholds: the signal screen values (`minPrr`, `minChiSquare`, `minCases`) belong in G3's `conf.d/G3.conf` and the quality check values (`maxRejectRate`, `rowCountTolerance`) in C5's `conf.d/C5.conf`.
3. Hand the guide to Nithin without helping. Every question they ask is a gap; fix the guide and list the fixes in `docs/results/F3.md`.

## Tests

No ScalaTest code (this task owns no Scala folder). Checks:

- `sbt "pipeline/console"` then `com.typesafe.config.ConfigFactory.load().getString("medsignal.dataDir")` returns `data`.
- With `-Dmedsignal.dataDir=/tmp/x` the same call returns `/tmp/x`.
- The other engineer reaches a green `sbt test` using only `docs/setup.md`.
