## Goal

A library that picks the four label sections we search and splits each section's text into sentences, each carrying character offsets into the section text. Every later step (matcher L3, negation L4, the passage shown in the app) depends on these offsets being exact: `sectionText.substring(startOffset, endOffset)` must equal the sentence.

## Context

Read `docs/pipeline-spec.md` section 5 (steps 1 and 2), `docs/data-sources.md` "Label sections used", `docs/contracts.md` (Bronze `label_section`, Silver `label_version`, Conventions) and the decision record `docs/decisions/F5-xmldoc-on-spl.md`.

- Extraction is rule-based only. No language model, no NLP library, no embeddings. Plain Scala.
- This task is a library. It registers no stage and writes no table. L5 calls it.
- Offsets are Java `String` indexes (UTF-16 code units), start inclusive, end exclusive.
- Not verified: how I5 renders paragraphs, lists and tables into `LabelSection.text` (whether a line break always means a block boundary). Open the JSON Lines for five labels before coding and record what you find in `docs/results/L1.md`. The rules below assume whitespace inside a paragraph is collapsed and `\n` separates blocks.
- Not verified: older (pre-2006 format) labels use separate "Warnings" and "Precautions" sections with other LOINC codes. contracts.md (final section, item 14) names them as 34071-1 (warnings) and 42232-9 (precautions), to be verified by F5. Either way, count how many reference labels lack `43685-7` and report it.

## Implementation steps

1. `Loinc`:
   ```scala
   object Loinc {
     val BoxedWarning = "34066-1"; val WarningsAndPrecautions = "43685-7"
     val AdverseReactions = "34084-4"; val DrugInteractions = "34073-7"
     val searched: Seq[String] = Seq(BoxedWarning, WarningsAndPrecautions, AdverseReactions, DrugInteractions) // priority order, used by L5
   }
   ```
2. `SentenceSplitter`:
   ```scala
   object SentenceSplitter {
     val Version: Int = 1                      // bump on any rule change; part of extractorVersion (L5)
     def split(text: String): Seq[Span]
   }
   ```
   Rules, applied in one left-to-right pass:
   1. Hard break: a run of one or more `\n` or `\r` characters always ends the current sentence.
   2. Soft break: one of `.`, `!`, `?`, optionally followed by closing characters `)`, `]`, `"`, `'`, then at least one whitespace character, then an upper-case letter, a digit, `(` or `[`. The sentence ends after the closing characters. End of text also ends a sentence.
   3. A `.` is not a break when the word immediately before it (letters and inner dots, compared case-insensitively) is one of `e.g`, `i.e`, `vs`, `cf`, `approx`, `fig`, `dr`, `inc`, `u.s`, or is a single letter (`E. coli`, `C. difficile`). Decimals (`1.5`) and section numbers (`5.1`) are safe already because no whitespace follows the dot.
   4. `;` and `:` are not sentence breaks (L4 uses `;` as a scope terminator inside a sentence).
   5. Trim each span: move `start` right and `end` left past whitespace. Drop spans that contain no letter or digit.
   Guarantees: spans are in order, do not overlap, and never start or end on whitespace. Use a tail-recursive function or a fold; no `var`.
3. `Sentences`:
   ```scala
   object Sentences {
     def select(sections: Dataset[LabelSection], versions: Dataset[LabelVersion])
               (implicit spark: SparkSession): (Dataset[LabelSection], Dataset[Reject])
     def split(sections: Dataset[LabelSection])(implicit spark: SparkSession): Dataset[LabelSentence]
   }
   ```
   - `select` keeps rows whose `loinc` is in `Loinc.searched` and whose (`setId`, `version`) exists in `versions` (left-semi join). Rows with another LOINC or no label version are filtered, not rejected: they are out of scope, not unusable.
   - Rejects from `select`: a row whose `text` is empty or blank (reason `empty section text`); and, when several rows share (`setId`, `version`, `loinc`), every row except the one with the longest text (reason `duplicate section`). Build `Reject(source = "label_section", file = "label_section", line = 0, raw = s"$setId:$version:$loinc", reason, runId)` (for a table input, `file` is the table name and `line` is 0); take `runId` as a parameter. The caller (L5) writes them with `Rejects.write`. Count duplicates on real data; if they are common, the fix belongs in I5 (subsections concatenated into one row), not here.
   - `split` is a typed `flatMap`: for each section call `SentenceSplitter.split(text)` and emit one `LabelSentence` per span with `text = section.text.substring(span.start, span.end)`.
4. No `RunMetrics` call here; the calling stage returns the counts in its `StageResult` and the runner records them.

## Tests

`SentenceSplitterSpec` (no Spark):

- "reproduces every sentence from its offsets": for each fixture text, every span satisfies `text.substring(start, end)` equal to the trimmed sentence and has no leading or trailing whitespace.
- "splits on a period followed by a capital": `"Nausea occurred. Vomiting was rare."` gives 2 spans.
- "does not split a decimal or section number": `"Doses above 1.5 mg were studied (see 5.1). Rash occurred."` gives 2 spans.
- "does not split after an abbreviation": `"Infections (e.g. Pneumonia) occurred. Stop the drug."` gives 2 spans; `"E. coli infection was reported."` gives 1.
- "splits on a line break": `"Headache\nDizziness\nNausea"` gives 3 spans.
- "keeps a semicolon inside one sentence": `"No cases were seen; however, rash occurred."` gives 1 span.
- "returns nothing for blank text": `"  \n "` gives an empty list.
- Property test (ScalaCheck): for any string, spans are ordered, non-overlapping and within bounds.

`SentencesSpec` (mix in `SparkTestSession`, fixture `L1/sections.jsonl`):

- "selects only the four codes": a row with LOINC `34067-9` is not in the output.
- "drops sections with no label version".
- "rejects a blank section": exactly one `Reject` with reason `empty section text`.
- "offsets reproduce the sentence from the stored text": join output back to the sections and compare `substring` with `text` for every row.
