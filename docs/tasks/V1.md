## Goal

A table, `gold.SignalHistory`, holding the signal list as it would have looked at the end of each quarter, built only from the FAERS data and label versions that existed then. It is the input to the backtest (V2), the class-effect history (V3) and the ranking model (V6). Without it the project cannot say whether it would have flagged a problem before the FDA did.

## Context

- Read `docs/pipeline-spec.md` sections 4, 5 and 10 ("Backtest"); `docs/contracts.md` sections "Common library" (`RunContext.asOfQuarter`), "Gold tables" (`Signal`), "Silver tables" (`Case`, `LabelVersion`), and the note "Phase 6 adds `SignalHistory` (Signal columns plus asOfQuarter)".
- "As of quarter Q" means: FAERS data with `quarter <= Q`, and label versions with `effectiveDate` on or before the last day of Q. Nothing dated later may influence a row.
- Do not re-implement counts, statistics, scoring or labeled status. Call the public functions of G1 (counts), G3 (signals) and L5 (labeled status) with a `RunContext` whose `asOfQuarter` is `Some(Q)`.
- The backlog lists only G3 as a dependency, but the labeled status needs L5 and S4 merged. Do not start until they are.

Verify before coding (contracts.md does not name these functions):

1. Open `medsignal/signals/counts/`, `medsignal/signals/signal/` and `medsignal/labeltext/labeled/`. Find the function in each that takes inputs (or a `RunContext`) and returns a `Dataset` without writing. Find out whether each already honours `ctx.asOfQuarter`.
2. Never call those stages' `run(ctx)` with an as-of quarter if `run` writes the live `gold.AdverseEventStat` or `gold.Signal`: that would overwrite production tables with historical values. If only `run` exists, or a function ignores `asOfQuarter`, open a small `[Enhc]` pull request on that task's package (split "compute" from "write"; accept the as-of filter), merged first. Do not copy their logic here.
3. Whether `gold.Signal` holds only pairs that pass the screen or all pairs. Either way, V2 decides "candidate" from the 2x2 counts with `Disproportionality.isCandidate`, so keep whatever G3 returns.
4. Whether C1 can run a single stage by name. Metrics are recorded by the runner (contracts.md decision 6): the stage returns `StageResult` and never calls `RunMetrics.record`.

`Case.quarter` is the quarter the case was first received (`init_fda_dt`, falling back to `fda_dt`, then the file quarter; contracts.md decision 11), and a case that is followed up later stays in its first quarter. So `quarter <= Q` keeps exactly the cases first received by Q.

Known limit, to be measured and reported, not fixed: `silver.case` keeps one row per case, and that row and its detail rows (drugs, reactions, outcomes) carry the content of the latest version. A case first received by Q but followed up later is counted as of Q with its later content, so a drug, reaction or outcome added in a follow-up can appear slightly early. A full replay from bronze is out of scope.

## Implementation steps

1. `Quarters` (public; V2, V3 and V6 call it):

   ```scala
   object Quarters {
     def parse(q: String): Option[(Int, Int)]          // "2024Q3" -> (2024, 3)
     def index(q: String): Option[Int]                 // year * 4 + (n - 1)
     def fromIndex(i: Int): String
     def endDate(q: String): Option[java.sql.Date]     // 2024Q3 -> 2024-09-30
     def of(d: java.sql.Date): String                  // 2024-08-15 -> "2024Q3"
     def range(from: String, to: String): Seq[String]  // inclusive, ascending
   }
   ```

   Quarter strings in this format sort correctly as text, so `quarter <= Q` on the column is valid.

2. `AsOfInputs`:

   ```scala
   object AsOfInputs {
     def cases(all: Dataset[Case], q: String): Dataset[Case]            // Case.quarter (first receipt) <= q
     /** Label versions known by the end of q, with isReference recomputed for that date. */
     def labelVersions(all: Dataset[LabelVersion], q: String): Dataset[LabelVersion]
   }
   ```

   Reference label as of Q, per `rxcui`, among versions with `effectiveDate <= endDate(Q)`:
   1. `LabelVersion.isReference` is true for every version of the ingredient's reference `setId` (contracts.md decision 13). If any version with `isReference = true` is in that set, take the one current at the end of Q: the latest `effectiveDate`, ties broken by the highest `version`;
   2. otherwise take the single-ingredient version with the latest `effectiveDate` (ties: brand first, then lowest `setId`);
   3. otherwise the drug has no label as of Q and its signals get `no_label`.

   Return the kept versions with `isReference` set to true only on the chosen row. Case-detail tables are restricted by a semi join on the as-of `caseid` set.

3. `AsOfSignals.build(q: String, inputs: ...)(implicit spark): Dataset[SignalHistory]`: counts via G1's function on the filtered silver tables; signals via G3's function; labeled status via L5's function with the as-of label versions and `gold.LabeledReaction`; then `SignalHistory.fromSignal(_, q)` with `triageStatus = "open"`. Background totals must come from the same as-of case set (all of FAERS up to Q, not only formulary drugs). Because a case stays in its first quarter, they must equal the sums over `quarter <= Q` of G1's gold `DrugQuarterTotal`, `ReactionQuarterTotal` and `QuarterTotal`; assert this in a test and in the step 6 check.

4. `AsOfStage` (`name = "backtest.asof"`, `cadences = Set(Full)`):
   - if `medsignal.evaluation.enabled` is not `true`, log "backtest.asof skipped (evaluation disabled)" and return `StageResult(0, 0, 0)`. The 40-odd rebuilds must not count against the 45-minute full rebuild of criterion 3;
   - cache the silver inputs once; compute `Quarters.range(from, to)`;
   - for each quarter in order: build, then write with `Delta.overwrite(ds, Tables.gold("SignalHistory"), Seq("asOfQuarter"))`. With `partitionBy` this is a dynamic partition overwrite (contracts.md, "Common library (F7) additions"): only that quarter's partition is replaced, so a re-run never duplicates rows. Do not use `Delta.append`. Use `foreach` over the sequence; no `var`;
   - log quarter, rows and seconds per iteration;
   - return `StageResult(rowsIn = cases in the last quarter's as-of set, rowsOut = total history rows, rowsRejected = 0)`. Do not call `RunMetrics.record`; the runner records the stage.

5. `stages/backtest.asof.conf`: `class = "medsignal.backtest.asof.AsOfStage"`, `after = ["signals.signal", "labeltext.status"]` (stage names from contracts.md).

6. Consistency check, run once on real data and reported: the history rows for the latest quarter must equal today's `gold.Signal` on (`rxcui`, `term`, `a`, `b`, `c`, `d`, `labeledStatus`). Any difference means an as-of filter is wrong.

## Tests

Fixtures in `pipeline/src/test/resources/V1/`: `case.json`, `case_drug.json`, `case_reaction.json`, `case_outcome.json`, `case_indication.json` (about 60 cases over 2020Q1 to 2020Q4, built so drug D1 with term T1 passes the screen from 2020Q3 on), `label_version.json` (D1: version 1 effective 2020-02-01 without T1, version 2 effective 2020-11-15 listing T1), `labeled_reaction.json`, `formulary.json`.

- `QuartersSpec` "endDate of 2024Q3 is 2024-09-30"; "endDate of 2024Q4 is 2024-12-31"; "of(2024-08-15) is 2024Q3"; "index difference between 2020Q1 and 2019Q3 is 2"; "range is inclusive"; "parse rejects 2024Q5".
- `AsOfInputsSpec` "cases after the quarter are excluded"; "a case first received in the quarter and followed up later is included"; "picks the reference version current at the quarter end when several versions of the reference setId exist"; "a label version effective one day after the quarter end is excluded"; "a version effective on the last day is included"; "falls back to the latest single-ingredient label when today's reference label did not exist yet"; "a drug with no version yet has no reference label".
- `AsOfSignalsSpec` "D1/T1 is absent or not a candidate as of 2020Q2 and is a candidate as of 2020Q3"; "D1/T1 is unlabeled as of 2020Q3 and labeled as of 2020Q4"; "counts as of 2020Q2 use only cases up to 2020Q2" (a, b, c, d checked by hand); "one row per rxcui, term and asOfQuarter"; "the latest as-of quarter equals a direct G3 plus L5 build"; "the stage does nothing when evaluation is disabled".
