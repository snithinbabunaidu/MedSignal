## Goal

A pipeline stage that loads the JSON Lines written by the `labels` module into the Delta table `bronze.label_section`, using the schema string generated by that module. The row count equals the JSON line count, and a test proves the schema string and the Spark case class agree, so the two modules cannot drift apart.

## Context

Read `docs/contracts.md` (bronze `label_section`, Paths, Common library), `docs/architecture.md` (Modules), `docs/pipeline-spec.md` sections 1 and 6 (Labels row) and `docs/tasks/I5.md` (the files this stage reads). Look at the `JsonLines` sample and DDL pasted in `docs/decisions/F5-xmldoc-on-spl.md` to see the real field spelling.

`pipeline` (Scala 2.13) and `labels` (Scala 3) share no classes. This task therefore declares its own `LabelSection` case class with the contract's fields; the DDL file is the bridge.

Files in `data/interchange/labels/` (`Settings.interchangeDir("labels")`):

- `sections-<stamp>.jsonl`: one `LabelSection` JSON object per line; a label version appears in one file only.
- `rejects.jsonl`: one file (contracts.md, decision 5) of objects `{file, reason, raw}` for labels I5 could not convert; I5 only ever appends lines to it.
- `label_section.ddl`: Spark DDL for `LabelSection`.

The stage name is `bronze.labels` (contracts.md, Stage names). The stage returns `StageResult` and never calls `RunMetrics.record`; `StageRunner` records the metrics (decision 6). Rejects are written with `Rejects.write(...)`.

## Inputs

The three kinds of file above, `RunManifest.loaded("labels")` and `RunManifest.watermark("labels.rejects")`.

## Outputs

- `Tables.bronze("label_section")`, not partitioned:
  ```scala
  final case class LabelSection(setId: String, version: Int, effectiveDate: String, title: String,
                                activeIngredients: Seq[String], isBrand: Boolean, loinc: String,
                                sectionTitle: Option[String], text: String)
  ```
- `Tables.ops("rejects")`, written with `Rejects.write(...)`: `Reject(source = "labels", ...)` for unreadable JSON lines and for every entry of `rejects.jsonl`.
- `run_manifest`: one entry per loaded `sections` file, `source = "labels"`, `unit` = file name, `checksum` = SHA-256 of the file, `watermark` = `Some(<stamp from the file name>)`. For `rejects.jsonl`: one entry per run that copied lines, `source = "labels.rejects"`, `unit` = `rejects.jsonl@<lines copied so far>`, `watermark` = `Some(<lines copied so far, zero-padded to 10 digits>)`.
- `run_metrics`: one row for stage `bronze.labels`, recorded by `StageRunner` from the returned `StageResult`.

## Implementation steps

1. Schema: `val schema = StructType.fromDDL(<contents of label_section.ddl>)`. Fail the stage with a clear message when the DDL file is missing or when its field names and types differ from `Encoders.product[LabelSection].schema` (compare name and data type, ignore nullability). A mismatch means the modules drifted; do not load anything.
2. `LabelJsonReader.read(path, fileName, schema, ctx): Loaded` (rows, rejects, linesIn):
   - read the file as text with line numbers (`spark.read.textFile(path).rdd.zipWithIndex`), so rejects can carry a line number;
   - parse each line with `from_json(col, schema)`;
   - a line is a reject when the parsed struct is null or any of `setId`, `version`, `loinc`, `text` is null: `Reject("labels", fileName, line, raw, "bad json line", ctx.runId)`; truncate `raw` to 2,000 characters;
   - null `activeIngredients` becomes an empty `Seq`; null `sectionTitle` stays `None`;
   - convert to `Dataset[LabelSection]`.
3. Stage (`name = "bronze.labels"`, `cadences = Set(Cadence.Daily, Cadence.Full)`):
   - list `sections-*.jsonl`, sorted by name;
   - under `Daily`, take files whose name is not in `RunManifest.loaded("labels")` and `Delta.append` their rows; under `Full`, take all files, union the rows and `Delta.overwrite`;
   - `rejects.jsonl` (may be absent): read it with line numbers. Under `Daily`, skip the first N lines, where N is `RunManifest.watermark("labels.rejects")` parsed as a number (0 when `None`); under `Full`, take every line. Each line taken gives one `Reject("labels", <file field>, 0, <raw field>, <reason field>, ctx.runId)`. When lines were taken, call `RunManifest.record("labels.rejects", "rejects.jsonl@<total lines>", Checksum.sha256(...), Some(<total lines, zero-padded to 10 digits>))` after the rejects are written;
   - write all rejects with `Rejects.write(...)`;
   - for each `sections` file check `linesIn == rows + rejects`, and throw with the file name if not;
   - `RunManifest.record("labels", fileName, Checksum.sha256(...), Some(stamp))` for every `sections` file taken, after its data is written;
   - return `StageResult(rowsIn = JSON lines read from the sections files, rowsOut, rowsRejected)`. Do not call `RunMetrics.record`; `StageRunner` times the stage and records the row. With no new file, return `StageResult(0, 0, 0)` and log `bronze.labels: no new files`.
4. Run the whole label path by hand: `sbt "labels/runMain medsignal.download.DailyMedDownloader"`, `sbt "labels/runMain medsignal.spl.SplToJsonLines"`, then `sbt "pipeline/runMain medsignal.common.StageRunner bronze.labels --cadence full"`.
5. No `var`, no `null` in Scala code; nulls from JSON are turned into `Option` or rejects at the reader.

## Tests

- `LabelSchemaSpec`: "DDL from the labels module matches the LabelSection case class" (names, order, types); "a DDL with a renamed field makes the stage fail before loading".
- `LabelBronzeStageSpec` (`SparkTestSession`; copy `I6/interchange` into the temp `dataDir`):
  - "row count equals JSON line count for a clean file" (6 lines, 6 rows, 0 rejects);
  - "a broken JSON line becomes one reject with its line number" (3 rows, 1 reject, line 4 or wherever the fixture puts it);
  - "lines equal rows plus rejects for every file";
  - "entries of rejects.jsonl are copied to ops.rejects with source labels";
  - "a second Daily run loads nothing";
  - "lines appended to rejects.jsonl after a Daily run are the only ones copied by the next Daily run";
  - "the stage returns its counts and StageRunner.run records one bronze.labels metrics row";
  - "a new sections file is appended without touching earlier rows";
  - "Full rebuild gives the same rows as two Daily runs";
  - "table schema equals the case class schema";
  - "activeIngredients round-trips as a sequence and sectionTitle as an option".

## Done when
